# Hamster Assets

런타임에서 AI 이미지를 생성하지 않고, 아래 독립 투명 PNG pose asset을 행동 상태와 조합한다.

- `idle.png`: 기본 대기
- `walk-a.png`, `walk-b.png`: 네발 걷기 프레임
- `sleep.png`: 몸을 말고 잠든 상태
- `sit.png`: 씨앗을 든 앉은 상태
- `read.png`: 앞발로 책을 든 상태
- `carry.png`: 돌멩이를 품은 상태

SVG 파일은 이전 도형 기반 시안으로, 런타임에서는 사용하지 않는다.

표시 크기는 모바일에서 약 96–160 CSS px를 기준으로 한다. 다른 종은 같은 폴더 구조로 순차 추가한다.
